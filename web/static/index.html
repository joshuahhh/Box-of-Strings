Using Box of Strings

      
Rewrite string diagrams with the mouse to prove properties of morphisms
        in monoidal categories. Start by picking a file from the list; the
        0-introduction file is a good first stop.


      
Rewriting (workbench)

      
    
        
  • Drag a node to move it. Dropping a node onto another packages them into a composite node.
    • 
        
  • Scroll over a node to cycle through the rewrites that apply to it (listed on the right).
    • 
        
  • Right-click a composite node to unfold it.
    • 
        
  • Click the small circle in the middle of a string to create an identity node.
    • 
        
  • Middle-click (or Shift+click) a composite node to turn its contents into a new operation.
    • 
        
  • Space applies an automatic rewrite step.
    • 
      


      
History bar (left)

      
    
        
  • Scroll over it to move through earlier diagrams; click a neighbouring diagram to animate to it.
    • 
      


      
Editing (at the end of a file)

      
    
        
  • Type an operation's letter (or click it on the left) to add it; scroll to add or remove strings.
    • 
        
  • Typing an unused letter starts a new operation: then type two digits, its number of inputs and outputs.
    • 
        
  • Backspace/Delete removes the last operation.
    • 
      


      
Tablets

      
The buttons at the bottom left are for tablets: ▲/▼ stand in for
        the scroll wheel and Unfold for right-click. They act on the
        last place you tapped on the diagram (marked with a small arrow), so tap
        a node, then press the buttons.


      
Files in the browser

      
The example theories from the project are built in. Changes the program
        makes to files (new operations, saved relations and proofs, exports) are kept
        in this browser only. Use Download changes to save them, Open
        file… to add your own theory files (they appear under uploads),
        and Reset to go back to the original files.

      
Text the desktop version prints in the terminal appears in the Console panel.
